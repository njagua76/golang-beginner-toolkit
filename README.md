# 🚀 Go Beginner's Toolkit

**An AI-Powered Learning Journey into Golang**

> Learn Go from scratch with practical examples, clear documentation, and hands-on experience.

## 📌 Quick Start

### Prerequisites
- Go 1.21+ ([Download](https://golang.org/dl))
- Git
- Any text editor (VS Code recommended)

### Installation (Linux/Mac)
```bash
# Clone the repository
git clone https://github.com/ann-jagua/golang-beginner-toolkit.git
cd golang-beginner-toolkit

# Run the example
go run main.go
```

## 🐛 Troubleshooting

| Issue | Solution |
|-------|----------|
| `go: command not found` | Install Go from [golang.org](https://golang.org/dl) |
| `undefined: someFunction` | Check function starts with capital letter (exported) |
| Code won't compile | Check Go syntax; use `gofmt main.go` to auto-format |

**More issues?** Check [Common Issues & Fixes](TOOLKIT.md#-common-issues--fixes) in TOOLKIT.md
